# MEGA Tool

**一个面向《1844年经济学哲学手稿》研究的数字人文工具，用于在 MEGA² 德文与中文版本之间进行连续对读、词句定位、版本比较和论文引用。**

[English README](README.md)

![德中连续对读界面](docs/screenshots/reader-desktop.jpg)

## 为什么做这个工具

MEGA Tool 直接来自我对青年马克思辩证法思想发生过程以及黑格尔—马克思关系的本科研究。

在阅读《巴黎手稿》时，我需要不断往返于 MEGA² 德文、中文译本、不同文本编排、印刷页码、PDF 页序和二手研究之间。把三个1844年手稿与马克思的穆勒笔记联系起来阅读时，这种定位需求更加明显。

普通 PDF 搜索可以找到一个词，却很难继续保存“这句话对应哪一段译文、位于哪个版本和印刷页、怎样回到原页核对、最后怎样形成论文引用”这一整条研究关系。

MEGA Tool 就是从这个实际研究工作流出发设计的。

## 核心研究工作流

### 德中连续对读

按阅读页连续查看德文与中文对应文本。即使对应关系是 1:N 或 N:1，一个完整对应组也不会被阅读分页拆开。

### 词句检索与原典定位

输入德文或中文词、短语或文段，查看带前后文的候选结果，定位原书印刷页，并直接跳回对应的阅读位置。

### 引用与原页核对

按照具体版本生成可复制的论文引用；本地配置对应 PDF 后，可以进一步打开来源页进行核对。

![词句定位与页码工作流](docs/screenshots/locator-v021.jpg)

项目还包括版本比较、术语分布、覆盖清单和研究数据审核等功能。

## 研究设计与我的贡献

这个项目围绕我自己在《巴黎手稿》研究中遇到的问题展开。

我确定了研究问题、文献范围、版本选择与底本配对，提出文本与德中对应规则、页码规则、引用规范、转录原则、功能需求和学术核验标准，并设计了“连续对读 → 词句检索 → 印刷页定位 → 原页复核 → 复制引用”的核心研究流程。

其中几项关键设计包括：

- **文献范围。** 第一阶段集中处理三个1844年手稿和马克思的穆勒笔记。
- **可追溯的德中对应。** 对应关系独立保存，允许 1:1、1:N 和 N:1；阅读分页不能破坏完整对应组。
- **不同页码承担不同功能。** 软件阅读页服务连续阅读，原书印刷页服务研究与引用，PDF 页序服务本地原页定位和核验。
- **引用跟随版本。** 引用模板绑定具体来源版本，并与 PDF 导航分开。
- **底本证据优先。** 扫描页清晰可读时按可见字形转录；真正存疑的读法单独标注，不用上下文静默改写原文。

我亲自核对了项目最初的德中对应关系。后续扩充时，我又引入了分层抽样和疑点定向核查，用来发现转录、对应和页码定位中的问题，并把人工发现的问题继续反馈到工具规则中。

## 一个具体的研究判断

在人工核对马克思的穆勒笔记时，我发现有一处 PDF 可见字形为 `trete`，而此前的数据整理曾将它改成 `freie`。

我指出这一错误、要求修正，并进一步明确项目的转录原则：清晰可见的底本文字优先；基于语境的猜测必须显式保留为疑点。界面现在会标出语义可疑但按底本照录的位置，并显示保留理由。纠错依据与处理过程见[转录复盘](docs/TRANSCRIPTION_REVIEW.md)。

这类问题也是我希望这个工具能够帮助研究者更容易发现和追溯的对象。

## 技术概况

项目使用 **Python** 与 **Streamlit**。研究数据以 UTF-8 JSON 保存，包含稳定文本 ID、版本元数据、德中对应关系、页码映射和审核状态。

核心模块分别负责语料读取、阅读页生成、检索、页码定位、引用生成、版本比较、统计和审核。自动化测试覆盖数据完整性以及主要的阅读、检索与页码工作流。

程序运行本身不依赖在线 AI API。

## 本地运行

使用 Python 3.11 或更新版本；项目已在 Windows / Python 3.14 上验证。

可按下方命令克隆仓库，也可在 GitHub 点击 **Code → Download ZIP** 后解压。使用 ZIP 时，先进入实际解压目录，再从创建虚拟环境的命令开始。

```powershell
git clone https://github.com/YangZhuo-KSM/MEGA-Tool.git
cd MEGA-Tool

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

随后打开 [http://127.0.0.1:8501](http://127.0.0.1:8501)。首次安装后可执行 `start.ps1`，或重复最后一条命令启动；在终端按 **Ctrl+C** 停止服务。依赖安装后可离线阅读。

macOS / Linux 可使用 `python3 -m venv .venv` 创建环境，并将 Windows 的 Python 路径替换为 `.venv/bin/python`。

## 使用本地 PDF

即使不配置 PDF，也可以使用对读、检索、比较和统计功能。

若需要原页预览和页码核验，可将自己持有的对应来源文件放入 `Asset_by_user/`，保持 [local_sources.example.json](local_sources.example.json)中列出的文件名；也可复制该文件为 `local_sources.json`，填写自己的绝对路径或项目相对路径。完整来源 PDF 由使用者提供。

页码映射通过文件哈希和总页数绑定已索引的 PDF。同一版本的另一份扫描文件可能需要重新建立映射。
