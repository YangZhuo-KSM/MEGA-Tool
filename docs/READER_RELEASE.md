# 连续对读与词句定位：0.2.1-reader-preview

2026-10-01，Asia/Hong_Kong。本版在已工作的页码定位基础上改变阅读组织和检索交互，后续版本比较的学术复核仍另行进行。

## 三种页的职责

- 阅读页：软件临时组织的双栏阅读内容。每个专题单独编号，永远不作为论文页码。当前异化劳动4页、穆勒评注7页，来自原有24组对应。
- 印刷页：研究检索、来源提示和引用的页码。正文上方汇总本阅读页的两侧印刷页，每个文本仍有独立来源入口。
- PDF页序：从1开始的内部地址。文本位置通过既有逐页映射解析，再由渲染器转换为底层从0开始的页面地址。没有全书统一偏移。

正常阅读、词句检索、引用和预览图注隐藏PDF页序。页码索引底部的“高级页码核验（含 PDF 页序）”开关开启后，才显示双向页码查询、原文件浏览和全部映射表。研究数据JSON导出仍保留PDF页序，方便核验与复现。

## 阅读页生成

`paris/reading.py`按专题及德文文本sequence排序原有对应组，动态生成仅含对应组ID、页号和估计高度的临时页面。它不保存另一份正文，不更新语料或审核记录。

默认每栏宽度估计为62个半角字符格，中文/全角字符占两格；每行增加12%换行余量，分别计算各文本段落行数。两侧分别累计正文、段落间距，再取较高侧并计入轻量来源控件空间。以44个估计行高为一页的目标预算，依顺序贪心装入完整组；下一组放不下就换页，超长组独占一页并允许滚动。

因此每页组数随两栏正文长度变化。1:1、1:N、N:1组都不会从中间拆开。分页只在组之间，原书页边界不参与切割。预算是桌面阅读的估计值，不声称测得浏览器真实像素高度；窗口宽度和字体会影响实际高度，但不会使页号因窗口变化漂移。

顶部和底部可翻页；连续浏览从选中阅读页开始显示后续页面。专题搜索和照录疑点筛选只筛选已有阅读页，保留页内全部前后文，不重排或重编号。两栏使用连续正文与细分隔线，长审核备注和研究记录折叠显示。

## 定位与引用流程

1. 输入德文/中文词、短语或较长文段，可限定来源。
2. 复用原Unicode检索：规范化、折叠空白、可选区分大小写，完整词边界只用于德文。保留原文字符位置。
3. 每个候选列出版本、印刷页、全部命中的上下文窗口和固定引用；同一关键词可出现多个候选，同一单元多个命中合并相邻上下文。
4. 点击“查看原页”按该单元所有精确位置逐一预览。重复印刷标签不合并PDF地址；跨页单元提供所有原页。
5. 点击“跳转到对读位置”打开所属阅读页，标出目标组并高亮原查询字句。比较版本通过已有比较关系连接到主读位置，明确提示比较关系待复核，并另显示命中的版本正文及其自己的引用。

精度限制：当前位置记录覆盖整个文本单元，没有逐字页边界。跨页单元的命中报告该单元所有页，不能断言某个词在其中哪一张页。长片段支持单元内的连续字面匹配，暂不跨两个独立单元拼接搜索，也不做模糊语义搜索或自动纠正历史拼写。

`paris/citations.py`按edition关联的source ID选取唯一模板；两种MEGA I/2呈现共用出版物模板，详情仍分别显示呈现方式。四个来源的书目信息和模板集中在BIBLIOGRAPHY，未重复写入文本。连续阿拉伯印刷页合并范围，非连续页保留列表；罗马数字、星号及前导零标签原样保留，不假设相邻。定位缺失或不完整时不生成貌似完整的引用。

引用展开显示书名斜体；“复制引用”复制不含Markdown星号的普通文字，方便脚注与笔记粘贴。浏览器拒绝剪贴板时选中备用文本，提示Ctrl+C。正文仍不恢复原书粗体、字重或斜体。

**书目信息与模板独立**：用户要求的MEGA IV/2引用模板使用1982；既有扫描底本元数据为1981，保持不变，引用旁提示此差异。中文单行本按指定2000年版模板输出，版权页尚未独立核验，界面继续提示。新增模板不升级任何核验状态。
