# 人工核查：分层抽样与疑点核查

2026-10-02，香港日期。此规则取代“每批6组全部由用户核验”的后续扩充要求。Codex继续整理和页面核对，程序检查全部结构及来源；研究者以抽样发现质量问题，直接用于论文的引文另外核对。

## 怎样选样本

- 按专题和两侧来源版本分层，每层再按文本长度分成相对长、短两类，在两类中可复现地随机抽取。试运行取每层20%，至少2组；不足2组则全取。小规模批次实际比例会偏高。
- 跨页接续、多单元对应、照录疑点各补一个代表组，允许一组覆盖多类风险。未解决字形或对应疑点单列；清楚的重复异常不要求逐处普查。
- 本轮范围为第5批以来的新增内容，原24组确认继续保留；原有mill_004疑点仍在待办中。相邻批次合并选样，避免机械要求每6组全部核对。
- 固定随机种子、候选范围、选中ID、选中理由和正文/来源指纹保存在data/sampling_plan.json；刷新页面及保存单条确认不会改变名单。正文、来源、疑点或范围改变后旧清单失效，须重新生成。上一版发行包保留旧清单。
- 扩充到新章节、新来源页段或更换提取方法后重新分层，轮换页段；选样不能只靠“读起来通顺”或模型置信度。该混合抽样用于发现问题，不保证统计代表性，不据此宣称95%置信或全文无误。

## 每个抽中组怎么查

1. 打开德中双方所有来源页，连同前后各一小段阅读。核对书名/呈现方式、印刷页、PDF页和跨页接续。
2. 对抽中的整组逐句比对：漏句、重复、错序、注释混入，及否定词、数量、人名、关键术语、历史拼写是否按底本记录。AI校订标记不代替这一步。
3. 检查德中起止和论证范围是否完整对应；允许一句对多句，不以字数接近为标准。中文译文按译本照录，不自行润色。
4. 看到语义异常时，检查它是否与PDF一致且有标注；已照录并标出的底本异常本身不算转录失败。无法辨认的候选保持待审。
5. 完整核过该组才点“确认对应”；只看过一个疑词时在备注记录局部结论，仍保留待审。建议备注“抽样核查：文字/对应/页码通过”或具体差错和位置。

## 发现错误后

- 错配、漏句/重复、顺序错误、错版错页、否定词或关键术语误录：本层暂停质量结论，保留问题组待审；由Codex检查同页、相邻组及同一提取方法的相关数据，再让研究者核对修正项和新增样本。
- 一般标点或空白误录：记录并修正，补抽同层至少1组；若重复出现则按系统性问题扩查。句义或引用受影响的标点按上一条处理。
- 一层两次扩查仍出现同类问题，改进提取/校订方法，或对该问题页段逐项检查；不要求研究者因此普查整部书。
- 可以记录“本轮抽查N组，未发现影响研究的错误”，同时列出范围、方法与未解决项；未抽中条目始终显示未人工核对，不能批量升为manually_verified。

## 使用边界

软件的逐条人工确认率只计算实际核过的条目，抽样完成与全文完整度分别报告。论文直接引用、核心论点所依赖的句子及关键统计命中，使用前再核原页；精确频次研究还需检查检索漏项和收录范围，不能仅凭转录样本通过保证全文统计正确。
